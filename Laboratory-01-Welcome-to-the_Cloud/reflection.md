# Reflection

## My Experience

This laboratory activity gave me my first practical experience working inside a cloud-based Linux environment using KillerCoda. I learned how to access the Linux terminal and use basic commands to explore the system.

## What I Learned

I learned how to check the current username, working directory, hostname, Linux distribution, kernel version, CPU information, memory, and available disk space. I also learned how to create directories and Markdown files using Linux commands.

Another important part of the activity was learning how to organize my work using GitHub. Creating a Cloud Computing Portfolio will allow me to keep my laboratory activities, documentation, screenshots, and other files organized throughout the semester.

## Challenges

One of the challenges I experienced was becoming familiar with Linux commands and understanding what information each command provides. I had to carefully check the terminal output and make sure that the required information was recorded correctly.

## Skills Developed

This activity helped me improve my Linux command-line skills, file and directory management skills, documentation skills, and familiarity with GitHub.

## Conclusion

Overall, this laboratory activity provided a useful introduction to working with Linux in a cloud-based environment. The skills I learned will help me complete future Cloud Computing laboratory activities and better understand cloud infrastructure and system administration.
