# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic concepts and practical skills needed to work as a cloud infrastructure engineer. The activity uses the KillerCoda Playground to provide a Linux environment where I can practice Linux commands, system administration, file organization, and documentation.

The activity also introduces the use of GitHub as a professional Cloud Computing Portfolio where laboratory activities, documentation, scripts, screenshots, and reflections can be stored throughout the semester.

## Objectives

By completing this laboratory activity, I learned how to:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Create and organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.
- Practice proper documentation for cloud computing activities.

## Activities Performed

During this laboratory activity, I performed the following tasks:

1. Accessed the Ubuntu Linux environment using KillerCoda.
2. Created and logged in to a new Linux user account.
3. Checked the current username, working directory, and hostname.
4. Gathered information about the Linux distribution, kernel version, CPU, memory, and disk space.
5. Created the required directory structure for the laboratory.
6. Created Markdown documentation files.
7. Created a GitHub repository for my Cloud Computing Portfolio.
8. Organized the laboratory files and screenshots.
9. Documented the activities and skills learned.

## Linux Commands Used

The following Linux commands were used during the laboratory activity:

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname of the system.
- `cat /etc/os-release` – displays Linux distribution information.
- `uname -r` – displays the kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays available disk space.
- `mkdir` – creates directories.
- `touch` – creates files.
- `cd` – changes the current directory.
- `ls` – lists files and directories.
- `nano` – opens a text editor for editing files.

## Skills Learned

Through this laboratory activity, I learned how to work with a Linux-based cloud environment and use basic Linux commands. I also learned how to gather system information, create and organize directories and files, and document technical activities using Markdown.

I also learned the importance of using GitHub to organize and maintain a professional Cloud Computing Portfolio. These skills will be useful for future laboratory activities involving Linux, cloud infrastructure, Docker, Kubernetes, monitoring, and system administration.
