# Google Cloud Platform Research

## Brief Overview

Google Cloud is Google's public cloud platform. It provides infrastructure, storage, databases, networking, containers, analytics, artificial intelligence, machine learning, and application-development services.

## Global Infrastructure

Google Cloud organizes infrastructure into **regions** and **zones**. Google states that regions are independent geographic areas containing zones, while zones are deployment areas within regions. Google Cloud's current global locations page lists 43 regions and 130 zones.

## Cloud Management Console

The **Google Cloud console** is a web-based interface used to manage and monitor Google Cloud applications and resources. It provides access to services such as Compute Engine, Cloud Storage, Cloud SQL, networking, Kubernetes, analytics, and AI services.

## Four Core Services

| Category | GCP Service | Purpose |
|---|---|---|
| Compute | Compute Engine | Provides virtual machines running in Google's infrastructure |
| Object Storage | Cloud Storage | Provides secure, durable, scalable object storage |
| Database | Cloud SQL | Provides managed MySQL, PostgreSQL, and SQL Server databases |
| Kubernetes | Google Kubernetes Engine (GKE) | Provides a managed environment for running containerized applications |

## Three Advantages

1. **Strong AI and machine-learning capabilities** – Google Cloud provides extensive AI/ML services and specialized infrastructure.
2. **Kubernetes expertise** – GKE provides a managed Kubernetes environment and is closely connected to Google's container ecosystem.
3. **Global network and infrastructure** – Google Cloud provides a worldwide infrastructure designed for performance, availability, and scalable workloads.

## Typical Enterprise Use Cases

Google Cloud can support AI and machine-learning workloads, analytics, containerized applications, web applications, databases, data platforms, and globally distributed services. It is especially attractive for organizations whose workloads depend heavily on data analytics, AI/ML, or Kubernetes.
