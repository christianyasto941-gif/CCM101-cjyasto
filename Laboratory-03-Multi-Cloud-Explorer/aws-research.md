# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a major public cloud platform that provides computing, storage, databases, networking, security, analytics, and many other cloud capabilities. AWS launched in 2006, beginning with services such as Amazon S3, and has expanded into a broad cloud service portfolio.

## Global Infrastructure

AWS organizes its infrastructure into geographic **Regions** and **Availability Zones (AZs)**. AWS states that each Region consists of at least three isolated and physically separate Availability Zones, with redundant networking between them. This design helps customers build applications that are highly available and fault tolerant.

## Cloud Management Console

The **AWS Management Console** is a web-based interface for accessing and managing AWS services and resources. Administrators can use it to create resources, configure services, monitor workloads, manage security permissions, and review account information.

## Four Core Services

| Category | AWS Service | Purpose |
|---|---|---|
| Compute | Amazon EC2 | Provides resizable virtual servers in the cloud |
| Object Storage | Amazon S3 | Stores and retrieves objects such as files and application data |
| Database | Amazon RDS | Provides managed relational database services |
| Networking | Amazon VPC | Provides isolated virtual networking for AWS resources |

## Three Advantages

1. **Broad service portfolio** – AWS provides a very large selection of infrastructure, database, storage, security, analytics, and application services.
2. **Global infrastructure** – Regions and Availability Zones allow organizations to design systems for geographic distribution and high availability.
3. **Scalability** – AWS services can be scaled according to workload requirements, allowing organizations to increase or decrease resources as needed.

## Typical Enterprise Use Cases

Enterprises use AWS for web and application hosting, backup and storage, databases, disaster recovery, analytics, content delivery, and large-scale application infrastructure. Its wide service selection also supports organizations that need many different cloud capabilities from one provider.
