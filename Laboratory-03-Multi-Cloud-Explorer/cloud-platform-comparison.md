## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is a strong choice when the main criterion is breadth of cloud services. Its long-running public-cloud portfolio covers compute, storage, databases, networking, security, analytics, and many specialized workloads.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the most natural choice for an organization already using Microsoft technologies. Its services are designed to work with Microsoft's enterprise identity, server, productivity, and hybrid-cloud ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for AI/ML and Kubernetes-focused workloads. Google Cloud provides AI infrastructure and services while also offering Google Kubernetes Engine (GKE) as a managed Kubernetes platform.

### 4. Which cloud platform would you personally choose and why?

I would choose **AWS** for a general-purpose organization because it provides a broad selection of services and supports many different workload types. However, I would change that choice when a client's requirements strongly favor another provider, such as Microsoft integration with Azure or AI/Kubernetes specialization with Google Cloud.
