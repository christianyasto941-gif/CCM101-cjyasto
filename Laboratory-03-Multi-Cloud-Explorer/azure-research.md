# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's public cloud platform. It provides infrastructure, platform services, databases, networking, identity, analytics, artificial intelligence, and application services for organizations.

## Global Infrastructure

Azure organizes its cloud infrastructure into geographic regions and availability zones. Microsoft describes availability zones as physically and logically separated datacenters with independent power, networking, and cooling. Azure regions are also associated with geographies that can serve as data-residency boundaries.

## Cloud Management Console

The **Azure portal** is Microsoft's web-based management interface for Azure resources. Users can create and manage virtual machines, databases, storage, networks, identities, monitoring resources, and other cloud services through the portal.

## Four Core Services

| Category | Azure Service | Purpose |
|---|---|---|
| Compute | Azure Virtual Machines | Provides scalable Windows or Linux virtual machines |
| Object Storage | Azure Blob Storage | Provides object storage for unstructured data |
| Database | Azure SQL Database | Provides a managed relational database service |
| Networking | Azure Virtual Network | Creates private and isolated networks for cloud resources |

## Three Advantages

1. **Microsoft ecosystem integration** – Azure is particularly suitable for organizations already using Microsoft products and technologies.
2. **Hybrid-cloud capabilities** – Azure provides services and networking options for connecting on-premises environments with cloud resources.
3. **Enterprise features** – Azure provides extensive identity, security, management, compliance, and infrastructure services for large organizations.

## Typical Enterprise Use Cases

Azure is commonly appropriate for organizations using Windows Server, Microsoft 365, Microsoft identity technologies, and other Microsoft enterprise products. It can also support application hosting, databases, virtual desktops, analytics, AI, backup, disaster recovery, and hybrid-cloud architectures.
