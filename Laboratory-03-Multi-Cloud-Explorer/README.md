# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity evaluates Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The goal is to compare their infrastructure, core services, strengths, and appropriate business use cases.

### Cloud Hosting Options

| Provider | Service that can host the Linux server |
|---|---|
| AWS | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machines |
| Google Cloud | Compute Engine |

All three services provide virtual-machine infrastructure suitable for hosting a Linux server. The final choice should consider the organization's existing ecosystem, required services, location, performance, security, and cost.
