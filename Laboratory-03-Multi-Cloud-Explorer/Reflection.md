# Mission 3 Reflection

Among the three cloud platforms, Google Cloud impressed me the most because of its strong focus on artificial intelligence, machine learning, data, and Kubernetes. I found it interesting that Google Cloud combines cloud infrastructure with technologies that are important for modern applications, especially applications that depend on large-scale data processing and AI workloads. However, I also learned that the “best” cloud provider depends on the requirements of the organization.

AWS, Azure, and Google Cloud have many similarities. All three provide virtual machines, object storage, databases, networking, identity and access management, monitoring, security services, and tools for application development. They also organize their infrastructure geographically so customers can design systems for availability, performance, and disaster recovery.

Business requirements strongly influence cloud platform selection because organizations do not all have the same environment. For example, the university in this activity already uses Windows Server, Microsoft 365, and Active Directory, so Azure is a logical choice because of its Microsoft ecosystem integration. An AI research company has different priorities, so Google Cloud can be attractive because of its AI/ML and Kubernetes capabilities. A global application may prioritize geographic coverage, scalability, and availability.

Acting as a Cloud Solutions Consultant taught me that selecting a cloud provider is not simply about choosing the most popular platform. A consultant must first understand the client's business goals, existing technology, budget, performance requirements, and future growth. The technical solution should support the business rather than force the business to adapt to a technology choice.

My GitHub Cloud Computing Portfolio improved because I added a structured multi-cloud investigation containing research, comparison tables, recommendations, a decision matrix, Linux investigation evidence, and a reflection. This activity also helped me practice organizing technical information in Markdown and connecting practical Linux knowledge with cloud infrastructure concepts.
